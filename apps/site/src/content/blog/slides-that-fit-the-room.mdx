A talk should make room for its material. A sentence needs a clear line length; a chart needs legible axes; a photograph needs enough space to be seen. Those demands change when the same talk moves from a laptop to a projector or a phone.

[Alkemist slides](/slides/) now use the available window directly. The default layout follows the content: headings and short introductions get room, images can sit beside prose, and interactive figures use a media layout. On narrow screens, columns stack. Reading mode preserves the ordinary document. Authors still write Markdown and separate slides with `---`.

Presenting has its own workspace. Overview opens a set of selectable cards; Speaker view keeps notes and the upcoming slide in a separate window. Fullscreen, a laser pointer, blackout, timed advance, and keyboard help are available without adding presentation markup to a talk. Figures keep their normal controls and pause when they leave the active slide.

The deck inherits the site's theme unless its author selects paper, chalk, or blueprint. A few CSS variables control its surface, text, accent, and type. Images in the opening slides also appear as covers in the library, making talks easier to recognize before opening them.

[The layout sampler](/slides/layout-sampler/) shows what ordinary headings, images, a quotation, a table, and code become. [The authoring guide](/docs/slides/) covers the defaults and the small escape hatches for unusual material.
