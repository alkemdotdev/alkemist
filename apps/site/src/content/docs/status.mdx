## Available in the foundation

- Astro 7.3.2 and a reusable workspace package boundary.
- `AlkLayout`, Paper/Graphite themes, locally served typography, responsive layouts, and print styles.
- MDX documentation and a development notebook built with the same theme as the demo.
- A component roadmap with canonical `Alk*` names.
- Cloudflare Pages configuration for production and branch previews.
- Build checks and a source-revision manifest for deployment verification.

## Next: real interactive evidence

The next feature milestone combines math, a diagram, a real CSV chart, and a real GLB viewer in one article. Then we expand to the full chart gallery, meshes, point clouds, splats, robotics, shaders, and simulations.

One-line components should make supported cases easy while preserving explicit options for units, coordinate systems, data interpretation, and rendering formats.

## Representation matters

NeRF training checkpoints are not universal browser assets. We will document browser-ready export pipelines and qualify method-specific viewers. Converting a radiance field into a mesh changes its representation and will be labeled accordingly.

An upstream library's capability is not automatically an Alkemist feature. A component becomes available here after implementation, documentation, and a representative browser demonstration.
