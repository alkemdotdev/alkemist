Use plain names for public components and exported custom types:

```ts
Layout;
Chart;
Model;
Figure;
ChartProps;
AssetManifest;
WidgetState;
```

`Layout`, `Chart`, `Model`, `Math`, `Code`, `Audio`, `Video`, and the fixed-study `Shader` are implemented. `Figure`, `AssetManifest`, and `WidgetState` above remain proposed names.

The package path identifies Alkemist's public API while authors can use familiar component names in their own pages.

Package names stay `@alkemdotdev/alkemist-*`. The integration function is `alkemist()`, and CSS tokens use `--alk-*`.

## Direct entries

Import each component from its lowercase, extensionless entry. Import its prop and content types from that same entry; the package has no root component barrel.

```astro
---
import Layout from '@alkemdotdev/alkemist-components/layout';
import type { LayoutProps } from '@alkemdotdev/alkemist-components/layout';
---

<Layout title="My notebook"><slot /></Layout>
```
