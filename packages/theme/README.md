# @alkemdotdev/alkemist-theme

Shared Alkemist palette, browser theme helper, fonts, and CSS.

- `@alkemdotdev/alkemist-theme/tokens.css` provides only named CSS tokens.
- `@alkemdotdev/alkemist-theme/theme.css` additionally applies fonts, global element styles,
  and the page reset.
- `@alkemdotdev/alkemist-theme` exports `getTheme`, `setTheme`, and `initTheme`.
- `@alkemdotdev/alkemist-theme/palette` exports the palette helpers.
